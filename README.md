# Традиции и праздники Китая

Познавательный многостраничный сайт о традиционных праздниках, обычаях, символах, кухне и искусстве Китая. Дипломная работа.

## Страницы

| Файл | Раздел | Интерактив |
|---|---|---|
| `index.html` | Главная | обратный отсчёт до ближайшего праздника |
| `holidays.html` | Календарь праздников | выбор года, фильтр по сезону, карточка праздника |
| `traditions.html` | Традиции и обычаи | раскрывающиеся блоки этикета |
| `symbols.html` | Символы и приметы | калькулятор китайского гороскопа |
| `cuisine.html` | Праздничная кухня | фильтр блюд, окно с рецептом |
| `art.html` | Искусство | «Ваше имя по-китайски» |
| `wishes.html` | Генератор пожеланий | случайное пожелание, копирование текста |

На всех страницах: адаптивное меню, кнопка «Наверх», плавное появление блоков при прокрутке.

## Технологии

HTML5, CSS3 и JavaScript без фреймворков и сборщиков. Шрифты подключены через Google Fonts (Playfair Display, PT Serif, Noto Serif SC, Ma Shan Zheng). Сервер не нужен: сайт размещается на GitHub Pages.

## Структура

```
css/style.css          общий стиль (палитра: пергамент, бордовый, золото, тушь)
js/main.js             меню, «Наверх», анимации, иллюстрации, обратный отсчёт
js/holidays-data.js    данные о 10 праздниках и даты на 2026–2028 годы
js/holidays.js         календарь праздников
js/zodiac.js           калькулятор гороскопа (таблица дат Нового года 1900–2050)
js/cuisine.js          блюда и рецепты
js/name.js             транскрипция имени иероглифами
js/wishes.js           генератор пожеланий
assets/img/            иллюстрации (список и промты — в assets/img/PROMPTS.md)
```

## Как открыть

Откройте `index.html` в браузере. Если иллюстрации ещё не добавлены, вместо них показываются плашки с иероглифами.
