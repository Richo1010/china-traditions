# Промты для иллюстраций сайта

Сгенерируйте картинки в ChatGPT, сохраните в формате **JPG** с точными именами файлов из таблицы и пришлите. Пока картинки нет, на её месте показывается бордовая плашка с иероглифом, поэтому сайт работает и без них.

**Общий стиль** (добавляйте в конец каждого промта):

> Style: realistic, serious and respectful, warm cinematic light, muted palette of parchment beige, deep burgundy red and antique gold, subtle mist, no text, no letters, no watermarks, not cartoonish.

Размер: для `hero.jpg` — горизонтальная 16:9 (например 1920×1080), для остальных — 4:3 или 3:2.
